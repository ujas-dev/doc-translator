Frequently Asked Questions

What file formats are supported?

We support PDF, DOCX, TXT, CSV, XLSX, PPTX, HTML, Markdown, and image files (JPG, PNG, TIFF, BMP).

How does layout preservation work?

For PDF and DOCX files, we extract text, translate it, and then reconstruct the document with the same fonts, spacing, and formatting.

Is my data secure?

Yes. All files are encrypted in transit and at rest. We never share your documents with third parties.

Can I use the API?

Yes! We provide a REST API for programmatic access. Check the API documentation for details.

How do translation styles work?

Choose from 5 styles: Faithful (literal), Fluid (natural), Creative (adaptive), Formal (business), or Casual (conversational).
